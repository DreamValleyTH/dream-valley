# Dream Valley v3 — บ้านดงเย็น (เว็บ เล่นบนมือถือได้)

**เล่นทันที:** เปิดลิงก์ Artifact "Dream Valley" ใน Claude (มือถือ/คอมก็ได้) · หรือดับเบิลคลิก `index.html` ในโฟลเดอร์นี้

## เข้าเกม / เซฟ
- **เริ่มใหม่:** ใส่ชื่อเล่น + รหัส 6 ตัว (ตัวอักษร/ตัวเลข, กด 🎲 สุ่มได้) เลือกเพศ และความยาว 1 วัน (5/10/15 นาทีจริง)
- **เล่นต่อ:** ใส่ชื่อ + รหัสเดิม → โหลดเซฟ · เซฟในเครื่อง และ (ถ้าเปิดผ่าน Artifact) ซิงก์ขึ้นคลาวด์ส่วนตัวด้วย

## มีอะไรในเกม
- 2 แผนที่ต่อกัน: **ฟาร์มยาย** (บ้าน ลาน ทางลูกรังลงตำบล แปลงผัก บ่อบัว สวนผลไม้) และ **ตำบล** (ถนนลาดยาง แถวร้านค้า อบต. สถานีตำรวจ รพ.สต. โรงเรียน ตลาด ศาลา วัด คลอง ทุ่ง ป่า) — ไปด้วย 🗺️ หรือเดินออกขอบแผนที่
- **NPC 33 คน** มีตารางเวลาไปทำงาน/กลับบ้าน · บทคุย 1,150 บท (เลือกหัวข้อ: ถามข่าว / ขอคำแนะนำ / คุยเล่น / ถามเรื่องเขา / ถามถึงคนอื่น) ตอบต่างกันตามนิสัย หัวใจ วัน เวลา และเหตุการณ์ในเรื่อง
- **เนื้อเรื่องรองของทุกคน** 129 งาน (3–5 ตอน/คน มีหลายตอนจบ) · 📜 แสดงงานที่ทำอยู่ งานที่รอรับ และ ⭐ เนื้อเรื่องหลักวันนี้
- **เนื้อเรื่องหลัก องก์ 1 "กลับบ้าน"** (28 วัน): ฉากเปิด 5 ฉาก → คุณธนาขอซื้อที่ → ประชุมประชาคม + โหวต → บ่อแห้ง → ข่าวลือผี → เมย์สืบเรื่องท่อ → ประชุมครั้งที่ 2 → ประกาศเลือกตั้ง → หน้าสมุดยายหน้าสุดท้าย (องก์ 2–3 เป็นโครงเรื่องใน `story/story.yaml`)
- **มือถือ 📱**: กลุ่ม LINE หมู่บ้าน (128 โพสต์ + นินทาเรื่องเรา 27 แบบ, กดถูกใจได้หัวใจ), แชตส่วนตัว (แม่ พ่อ เพื่อน NPC), หอกระจายข่าว, สมุดยาย (หน้าไดอารีที่ปลดล็อกจากเรื่องรอง), งาน, รายชื่อ, ตั้งค่า · แอปธนาคาร/กล้อง/ขายออนไลน์ = เร็วๆ นี้
- เสียงชาวบ้านคุยกันเองตอนเดินผ่าน 242 บรรทัด + บทคุยคู่ 34 บท · การ์ดเหตุการณ์ · ผีพื้นบ้านหลัง 21:00
- ฟาร์ม: พรวน ปลูก รดน้ำ เก็บเกี่ยว ขายที่ร้านเฮง/ลานข้าว/ตลาด · ต้นไม้ · หาของซ่อนตามทาง · แรง/นั่งพัก/กิน/นอน/เป็นลม

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` `style.css` | หน้าเกม · `artifact.html` = ตัวเดียวกันสำหรับเผยแพร่เป็น Artifact |
| `js/core.js` | สถานะ เซฟ (ชื่อ+รหัส) เงื่อนไข `when` และผล `effect` |
| `js/world.js` | แผนที่ เดิน หาทาง เวลา วาดภาพ |
| `js/farm.js` | แปลงผัก ต้นไม้ บ้าน นอน/เป็นลม วันใหม่ |
| `js/people.js` | ตาราง NPC บทคุย ร้านค้า งาน เสียงรอบตัว |
| `js/story.js` | ฉากเนื้อเรื่อง การ์ด ผี LINE |
| `js/ui.js` `js/main.js` | HUD แผง มือถือ หน้าเข้าเกม |
| `data/*.js` | **สร้างอัตโนมัติ** จาก YAML — ห้ามแก้มือ |
| `cards.js` | การ์ดเหตุการณ์ (แก้ได้ตรงนี้) |
| `tools/build_world.py` + `worldlib.py` | สร้างแผนที่ทั้งสอง (พื้นผิวขอบธรรมชาติ เงาอบในพื้น หญ้าโทนตามภาพตัวอย่าง) |
| `tools/build_chars.py` `build_icons.py` | ตัวละคร/ภาพหน้า/ไอคอน |
| `tools/compile_data.py` `validate.py` | รวมบท YAML → data/*.js และตรวจไอดี/ไอเทม/สถานที่ |

**แก้บท:** แก้ `docs/dialogue_v3/<id>.yaml` หรือ `story/*.yaml` → `python tools/compile_data.py <โฟลเดอร์ที่มี dialogue/ story/ ref/> .` → `python tools/validate.py <โฟลเดอร์เดียวกัน>`
