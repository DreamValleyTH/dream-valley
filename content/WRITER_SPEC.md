# Dream Valley — สเปกงานเขียน (บทคุย เนื้อเรื่อง เควสต์ LINE) สำหรับเกมแบบแตะจอ

อ่านไฟล์นี้ให้จบก่อนเริ่ม ทุกคนที่เขียนใช้สเปกเดียวกัน เพื่อให้เกม (JavaScript) อ่านข้อมูลได้โดยตรงและเนื้อเรื่องไม่ขัดกัน

## 0. เกมคืออะไร
- เกมเว็บ/มือถือ จำลองชีวิตชนบทไทยภาคกลาง (ตำบลบ้านดงเย็น) แนว Stardew Valley ภาษาไทยทั้งหมด
- ผู้เล่น = หนุ่ม/สาวอายุ 20–25 หมดไฟจากงานกรุงเทพฯ กลับมาดูแลบ้านและที่ดินของ **ยายเพียร** ที่เพิ่งเสีย (ชาวบ้านเรียกผู้เล่นว่า "หลานยายเพียร")
- ควบคุมแบบแตะจอ: แตะเดิน แตะคน → เมนู (คุย / ให้ของ / ขาย / ซื้อ / งาน) · กด "คุย" แล้วเลือกหัวข้อ → บทคุยโต้ตอบ (convos) ที่ผู้เล่นเลือกคำตอบได้
- เวลาในเกมเดินเอง 06:00–24:00 (1 วัน = 5–15 นาทีจริง) · หลัง 21:00 นอกบ้านมีผี · การกระทำใช้แรง
- แผนที่ที่เล่นได้ตอนนี้: **farm** (ฟาร์มยาย) และ **town** (ใจกลางตำบล รวมวัด โรงเรียน ตลาด) — ห้ามสร้างเควสต์ที่ต้องไปที่อื่น (ทุ่งนา ป่า อ่างเก็บน้ำ อำเภอ ใช้เป็นแค่เรื่องเล่าในบทพูดได้)
- โทรศัพท์ผู้เล่นมีแอป **LINE กลุ่มหมู่บ้าน "บ้านดงเย็น ม.3 💚"** ข่าวลือ ประกาศ สติกเกอร์ สวัสดีวันจันทร์ เลขเด็ด ข่าวปลอมสุขภาพ บัญชีอวตาร และแชตส่วนตัวกับคนที่สนิท

## 1. น้ำเสียง (สำคัญที่สุด)
- **ต้องเหมือนคนคุยกันจริง:** ประโยคสั้น พูดไม่จบ แทรกเรื่องอื่น แซว ตอบอ้อม ขี้บ่น ลืม เล่าเรื่องคนอื่นแทรก ใช้คำลงท้ายตามวัย/ตัวละคร ไม่เทศนา ไม่เป็นภาษาเขียน ไม่สรุปข้อคิด
- ใช้คำติดปาก สำเนียง มุกประจำตัว ตามช่อง `voice` ในไฟล์ yaml ของตัวละครนั้น และตาม `docs/design/08_people.md` หัวข้อ 8.8 (มีตลกร้าย 🖤 หรือไม่)
- **ตลกร้ายการเมืองท้องถิ่น** (เจ้าของสั่งให้ใส่เยอะ): งบหาย โครงการทำแค่ป้าย ถนนซ่อมทุกปีก่อนเลือกตั้ง ซองกฐินหาเสียง ประชุมยาวไม่ได้ข้อสรุป รถแห่ บัญชีอวตาร คืนหมาหอน เงินทอน ญาตินายกฯ ได้งานรับเหมา ป้ายไวนิลหน้าอบต. ฯลฯ — เสียดสี "ระบบ" และตัวละครสมมติเท่านั้น
- **นินทากันเอง:** ตัวละครพูดถึงกัน (ข่าวลือ ความลับ ความบาดหมางเล็กๆ ความรักแอบๆ) อ้างถึงกันข้ามไฟล์ได้ ใช้ชื่อเรียกตามตาราง §3
- ตัวละครอบอุ่น (พระอาจารย์สุเมธ หมอแอน ยายบัว เณรต้น) ไม่มีตลกร้าย แต่มีอารมณ์ขันอ่อนโยนได้
- **เส้นแดง (ห้ามเด็ดขาด):** ห้ามชื่อ/อ้างนักการเมืองจริง พรรคจริง แบรนด์จริง โลโก้ ห้ามแตะสถาบันพระมหากษัตริย์ ห้ามล้อพระพุทธเจ้า คำสอน พิธีกรรม (ล้อพุทธพาณิชย์ได้เฉพาะวัดในอำเภอ) วัดดงเย็นดีเสมอ · ตัวละครที่จีบได้เป็นผู้ใหญ่ทั้งหมด ฉากรักห้ามมีเนื้อหาทางเพศ · เด็ก (มิว โอ๊ต เณรต้น) ห้ามพูดหยาบ ห้ามเกี่ยวกับเรื่องรัก · ผีห้ามน่าเกลียดทางเพศ · กู/มึง ใช้ได้แค่เพื่อนสนิทคุยกันเอง (banter) ไม่ใช้กับผู้เล่น
- ราคาและค่าเงินอิงราคาจริงในไทยปัจจุบัน (ดู `ref/items_catalog.json` และ `docs/prices/*.csv`)

## 2. ตัวแปรในข้อความ
- `{player}` ชื่อผู้เล่น · `{p}` ผม/หนู · `{k}` ครับ/ค่ะ · `{kq}` ครับ/คะ (ใช้ `{kq}` หลัง นะ/สิ/ล่ะ/เหรอ/ไหม/หรือเปล่า/นี่ และท้ายคำถาม) · `{item}` ชื่อของ
- คำพูดของผู้เล่น (`text` ในตัวเลือก) เขียนให้ใช้ได้ทั้งชายและหญิงด้วยตัวแปรข้างบน ผู้เล่นเรียกผู้ใหญ่ว่า ป้า/ลุง/ยาย/ตา/พี่/หลวงพ่อ(พระ) ตามวัย
- ผู้เล่นมี 3 สไตล์คำตอบให้เลือก (ไม่ต้องครบทุกบท): ใส่ใจ/อบอุ่น · ขำ/แซว · ห้วน/ไม่สนใจ/เห็นแก่ตัว — ไม่ใช่ถูก-ผิดชัด ผลหัวใจต่างกันเล็กน้อย (-2 … +2)

## 4. ไอเทม
- พืชของผู้เล่น: `chili` (พริก) `basil` (กะเพรา) `corn` (ข้าวโพดหวาน) `morning_glory` (ผักบุ้ง) — ได้จากแปลงผัก
- ของจากฟาร์ม/หาของ: `mango` `tamarind` `wood` (ไม้ฟืน) `stone` `ant_egg` (ไข่มดแดง) `mushroom` (เห็ดโคนไม้) `mush2` (เห็ดระโงก) `marble` `honey` `worm`
- ของซื้อได้ในตำบล: เลือกจาก `ref/items_catalog.json` (ใช้ id ตามไฟล์ เฉพาะตัวที่มี `icon`) — เกมจะให้ร้านที่เกี่ยวข้องขายของที่ถูกอ้างในเควสต์ให้อัตโนมัติ ระบุร้านใน `sold_at` ของเควสต์ (place id) ถ้าเป็นของซื้อ
- อย่าคิดไอเทมใหม่ที่ไม่มีในรายการ

## 6. รูปแบบ `convos` (บทคุยโต้ตอบ) — ดูตัวอย่างเต็ม `ref/taew_convos_example.yaml`
```yaml
convos:
  - id: ann_n_dengue          # ขึ้นต้นด้วย id ตัวละคร ไม่ซ้ำ
    topic: news               # react | news | advice | smalltalk | self | others
    once: true                # (ไม่บังคับ) ครั้งเดียว · ไม่ใส่ = วนได้ทุก 7 วันในเกม
    when: { heart_min: 2, heart_max: 10, day_min: 3, time: morning|noon|evening, rain: true, flag: x, not_flag: y, has_item: mango }
    npc: "ประโยคเปิด"
    set_flag: ann_x           # (ไม่บังคับ)
    options:
      - text: "คำพูดผู้เล่น{k}"
        heart: 1
        reply: "ตอบกลับ"
        take: { mango: 1 }     # (ไม่บังคับ) ให้ของ — ตัวเลือกจะโผล่เฉพาะตอนมีของ
        set_flag: ann_y
        next:                  # (ไม่บังคับ) ตัวเลือกรอบ 2 (รูปแบบเดียวกัน ลึกได้ 2 ชั้น)
          - text: "…"
            heart: 0
            reply: "…"
```
- `react` = ตัวละครทักเองเรื่องที่เพิ่งเกิด (ธงเนื้อเรื่อง ข่าวลือเรื่องผู้เล่น อากาศ ของในกระเป๋า) ขึ้นแทนคำทักทาย วันละเรื่อง เรียงสำคัญก่อน
- จำนวนต่อตัว: **ตัวหลัก (♥ และ taew, ann, sumet, bua, heng, may, thana, somsak, wichai, prasert, sathian, noi) 34–40 บท** · ตัวรอง 24–30 บท · เด็ก 18–22 บท
- กระจาย: react ≥8 (ผูกกับธงเนื้อเรื่อง §8 อย่างน้อย 4 บท + ธง §5 + ข่าวลือ) · news ≥5 · advice ≥4 · smalltalk ≥5 · self ≥4 (บางบทล็อกด้วย heart_min 3/5/7 ให้เปิดเผยเรื่องลึกขึ้นตามความสนิท) · others ≥5 (นินทา/พูดถึงคนอื่น)
- ทุกบทมี 2–3 ตัวเลือก อย่างน้อย 1/3 ของบทมี `next`

## 7. รูปแบบ `quests` (เรื่องรองของแต่ละคน) — ใส่ในไฟล์เดียวกับ convos
แต่ละตัวละครมีเรื่องรอง 1 สาย 3–5 ตอน (เด็ก 2–3 ตอน) ที่เล่าปมของตัวเอง ต่อกันเป็นเรื่อง จบได้หลายแบบตามตัวเลือก
```yaml
quests:
  - id: ann_q1
    npc: ann
    title: "ยุงลายหลังโรงเรียน"           # ชื่อสั้นในหน้า 📜 งาน
    desc: "หมอแอนขอให้ช่วยคว่ำโอ่งรอบตำบล"  # 1 บรรทัด
    start: { heart_min: 1, day_min: 2, flag: x, not_flag: y }   # เมื่อไหร่ตัวละครจะชวน
    offer:                                 # บทชวน (รูปแบบเดียวกับ convo ไม่มี id/topic) ตัวเลือกที่ต้องรับงานใส่ accept: true
      npc: "ประโยคชวน"
      options:
        - text: "ได้เลย{k}"
          accept: true
          heart: 1
          reply: "…"
        - text: "ไว้ก่อนนะ{kq}"
          reply: "…"
    steps:
      - goal: { type: give, npc: ann, item: chili, n: 3 }
        # type: talk {npc} · give {npc,item,n} · have {item,n} · pay {npc,n} (จ่ายเงิน) · visit {place, from:"HH:MM", to:"HH:MM"} · days {n} (รอ n วัน) · flag {flag}
        hint: "เอาพริก 3 เม็ดไปให้หมอแอนที่ รพ.สต."
        done:                              # บทตอนทำขั้นนี้สำเร็จ (รูปแบบ convo ไม่มี id/topic) — ใส่ตัวเลือกที่แตกเรื่องได้ ตัวเลือกตั้ง set_flag ได้
          npc: "…"
          options: [ { text: "…", heart: 1, reply: "…", set_flag: ann_q1_kind } ]
    sold_at: { chili: null }               # (ไม่บังคับ) ถ้าต้องใช้ของซื้อ บอก place ที่ขาย
    reward: { money: 150, heart: 2, items: { honey: 1 }, set_flag: ann_q1_done, line: { from: ann, text: "โพสต์ในกลุ่ม LINE หลังจบ" } }
  - id: ann_q2
    start: { flag: ann_q1_done, heart_min: 3, day_min: 6 }
    ...
```
- เรื่องรองต้องเล่าความลับ/ปม/ความฝันของตัวละครจากไฟล์ yaml ของเขา (เช่น บอลลังเลไประยอง เมย์ถูกขู่ ตั้มจบปริญญาแต่อยู่กะดึก) ตอนท้ายมีทางเลือกที่เปลี่ยนชีวิตเขาจริง และ NPC อื่นพูดถึงผลลัพธ์ได้ (ใส่ react convo ที่ใช้ธงนั้นในไฟล์ของตัวเองด้วย)
- งานต้องทำได้จริงในเกม (ไอเทม §4 แผนที่ §0) ไม่ยากเกิน ไม่ซ้ำรูปแบบเดิมๆ (ไม่ใช่ "เอาของ X ไปให้" ทุกตอน — สลับ talk/visit ตอนกลางคืน/pay/days/ให้ของ/เลือกข้าง)
- ตัวละครที่จีบได้: ตอนสุดท้ายของเรื่องรองต้องมีหัวใจ ≥7 และปลดธง `<id>_romance_open` (ระบบแฟนทำทีหลัง) — ห้ามมีเนื้อหาทางเพศ

## 8. เนื้อเรื่องหลัก (โครงที่ทุกคนต้องยึด — คนเขียนเนื้อเรื่องหลักขยายเป็นตอนๆ)
**องก์ 1 "กลับบ้าน" (วันที่ 1–28) — เล่นได้เต็มในเวอร์ชันนี้**
1. วันที่ 1 `story_arrived`: มาถึง จดหมายยาย ป้าแต๋วทัก ลุงเชิดเป็นคนขับรถเมล์มาส่ง
2. วันที่ 2–4 `story_town_intro`: ไปใจกลางตำบลครั้งแรก รู้จักร้านต่างๆ ผู้ใหญ่สมศักดิ์ประกาศทักทาย "หลานยายเพียร" ทางหอกระจายข่าว (ซ้ำสามรอบ)
3. วันที่ 3+ `story_deed`: เจอสมุดบันทึกยายหน้าแรก (หน้ากระจายอยู่ทั่วตำบล 8 หน้า ได้จากเรื่องรองของคนแก่ๆ: bua, thongbai, chan, sommai, phueak, jamrat, taew, sumet — ธง `diary_<npc>`) ในบันทึกยายเล่าว่ายายแอบช่วยตำบลไว้หลายเรื่อง
4. วันที่ 5 `story_thana_visit`: คุณธนามาที่ฟาร์ม เสนอซื้อที่ดินยาย 1.2 ล้าน "ทุกอย่างจะง่ายขึ้นสำหรับทุกคน" — ผู้เล่นตอบได้ 3 ทาง: ปฏิเสธ (`thana_refused`) / ขอคิดดูก่อน (`thana_maybe`) / ถามราคาเพิ่ม (`thana_haggled`)
5. วันที่ 7 `story_meeting1`: ประชุมประชาคมที่ศาลา โหวตงบ อบต. 1.5 ล้าน: ระบบน้ำ / ถนนลาดยาง / ตลาดนัด — นายกฯ วิชัยพูดวน กำนันหลับ เสี่ยเฮงเสนอให้ทำถนน (รถบรรทุกลานเขาจะได้วิ่ง) กล้าเสนอระบบน้ำ ป้าแต๋วอยากได้ตลาด ผู้เล่นโหวต (`vote_water` / `vote_road` / `vote_market`) ผลโหวตประกาศวันที่ 8 (`meeting1_result_<x>`) — ตลกร้าย: สุดท้ายเงินถูกแบ่งเป็น "ศึกษาความเป็นไปได้" ไปครึ่งหนึ่ง
6. วันที่ 10–14 `story_well_dry`: บ่อหลังร้านป้าแต๋วแห้ง ตามด้วยบ่อบ้านลุงสมหมาย ชาวบ้านลือว่าบริษัทสูบน้ำบาดาล เมย์เริ่มสืบ ปาล์มเอาเครื่องวัดระดับน้ำมา
7. วันที่ 15 `story_ghost_rumor`: มีข่าวลือผีโผล่ที่ที่ดินบริษัท คนงานลาออก ยายบัวว่า "ผีไม่ชอบคนดูดน้ำจากแม่ธรณี" (ตลกปนน่ากลัว)
8. วันที่ 18 `story_may_evidence`: เมย์ขอให้ผู้เล่นช่วย (ถ้าหัวใจเมย์ ≥3) ถ่ายรูปท่อตอนกลางคืน — เลือกช่วย (`helped_may`) / ไม่ช่วย
9. วันที่ 21 `story_meeting2`: ประชุมครั้งที่ 2 ธนาเสนอ "โครงการ CSR" แจกถังน้ำพร้อมโลโก้บริษัท ชาวบ้านแตกเป็นสองฝ่าย
10. วันที่ 25–28 `story_act1_end`: ข่าวประกาศเลือกตั้งนายก อบต. ป้ายหาเสียงขึ้นเต็มเสาไฟ จดหมายยายหน้าสุดท้ายที่พบ (ถ้ามีหน้าสมุด ≥5) เผยว่ายาย "เคยเซ็นค้ำประกันอะไรบางอย่างไว้กับตำบล" → ปูองก์ 2 (`act1_done`)
**องก์ 2 "น้ำใต้ดิน" และ องก์ 3 "ที่ดินของใคร"** — เขียนเป็นโครงเรื่องในเอกสาร ยังไม่ต้องเป็นข้อมูลเล่นได้ (เลือกตั้ง คืนหมาหอน ผู้เล่นลงสมัครได้ ส.ป.ก. เป็นโฉนด ฉากจบหลายแบบ)

ธงเนื้อเรื่องที่ตัวละครอ้างใน react ได้: `story_arrived` `story_town_intro` `story_thana_visit` `thana_refused` `thana_maybe` `thana_haggled` `story_meeting1` `vote_water` `vote_road` `vote_market` `meeting1_result_water` `meeting1_result_road` `meeting1_result_market` `story_well_dry` `story_ghost_rumor` `story_may_evidence` `helped_may` `story_meeting2` `act1_done`

## 9. ส่งงาน
- เขียนไฟล์ YAML ตามที่ได้รับมอบหมาย ตรวจด้วย `python3 -c "import yaml;yaml.safe_load(open(F))"` ต้องผ่าน · ใช้ "…" (double-quote) ครอบทุกข้อความ ห้ามมี " ซ้อนข้างใน (ใช้ ‘ ’ หรือ “ ” แทน)
- อ่านไฟล์ตัวละครเดิมใน `ref/<id>.yaml` ทั้งหมดก่อนเขียน (voice, lines, choices, banter) ห้ามขัดกับข้อมูลเดิม ห้ามคัดลอกบรรทัดเดิมมาซ้ำ
